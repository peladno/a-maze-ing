## 4. Learned / 学んだこと

- Poetry is a better fit for this project because it provides deterministic locking, separates runtime and dev dependencies, and gives us a build backend without extra setup.
- The decision is defensible only if the reasoning is described accurately: the subject allows multiple package managers, and Poetry was chosen for concrete project needs.
- Environment constraints matter: a Windows machine can block `make` checks and CRLF-related breakage is a real risk if `.gitattributes` is missing.
