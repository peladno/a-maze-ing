## 4. Learned / 学んだこと

- **Independent loops are `E − V + 1`**, and a width by height board holds at most `(width − 1) × (height − 1)`,
  one per 2x2 block. That is why 3x2 is the smallest board for the default mode.
- **`*` in a signature makes the parameters after it keyword-only.**
- **`is None`, not truthiness,** for a seed: `seed=0` is a real seed. →
  [`python-truthiness-and-none.md`](../learning_log/python-truthiness-and-none.md)
- **`random.randrange` uses the shared generator; `Random(seed)` is a separate one** whose sequence nothing else
  can disturb.
