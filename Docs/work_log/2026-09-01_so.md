## 1. Done / やったこと

- **`neighbours` and `open_neighbours`** — `commit 238d485`. The first answers "what is next to me"
  and ignores walls; the second is the same stream filtered by `is_open`. Positions outside the grid
  and cells reserved for the pattern are dropped by `neighbours`, so no caller checks for either.
- **`rows`** — two lines. It iterates `self._grid` directly rather than counting through
  `range(self.height)`: the index was only ever a means to reach the row, and not having one removes
  a place to get it wrong.
- **Chose `_grid` over `walls_at` inside `rows`.** `rows` touches every cell, so going through
  `walls_at` would run the bounds check width × height times on positions already known to be
  inside. `rows` is inside the class; hiding the layout is for callers, not for the class itself.
- **Six tests added, eighteen in total.** The last one cross-checks `rows` against `walls_at` over
  every cell of a **carved, non-square** maze — the only shape where an index-order mistake in
  either of them can show up.
- **Docstrings in NumPy sections**, then **stripped of internal identifiers**. Docstrings ship with
  the code and are read by the evaluator, so `W12` and `decision 3.2` were replaced by what they
  actually mean. Subject section numbers stayed: the evaluator has the subject and can follow them.
- **Merged into `main`** — `commit 9a54147`, resolving the conflict on `maze/maze.py` in favour of
  this branch, as agreed. `maze/__init__.py` is javi's and stayed.
