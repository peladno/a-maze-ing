## 4. Learned / 学んだこと

- **An explicit stack turns recursion into a loop**, and marking a cell when it is pushed is what bounds the loop
  to O(V).
- **A passing test proves little until something breaks it.** Every test today was checked against a
  deliberately broken copy of the generator (mutation testing).
- **`capsys`** captures what a function prints, which is how "the generator prints nothing" became a test.
- [`python-generators.md`](../learning_log/python-generators.md) — a generator is walked once and has no length.
