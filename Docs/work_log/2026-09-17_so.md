## 4. Learned / 学んだこと

- [`bfs-and-shortest-path.md`](../learning_log/bfs-and-shortest-path.md) — **new**: stack against queue,
  `collections.deque`, and why the first arrival in BFS is a shortest route.
- **`list.reverse()` changes the list and returns `None`; `path[::-1]` makes a new, reversed list.**
- **`zip(path, path[1:])` gives consecutive pairs** and stops at the shorter one, so no `- 1` to forget.
- **A comma, not the brackets, makes a tuple:** `table[dx, dy]` looks up the key `(dx, dy)`.
