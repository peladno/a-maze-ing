## 4. Learned / 学んだこと

- Combining ANSI attributes (e.g. background `44` + foreground `97`) allows clean tile-based distinctions in terminal ASCII renderers without external GUI libraries.
- Checking for optional attributes via `hasattr` / `getattr` in the renderer maintains clean interface decoupling between the generator engine and the visualizer.
