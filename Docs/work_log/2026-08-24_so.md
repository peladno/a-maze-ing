## 1. Done / やったこと

- **`open_passage`** — `commit c62b61e`. Validates both positions, finds the direction from the
  difference between them, and clears the wall on **both** sides. Nothing else in the class writes
  to the grid, so decision 3.3 is now enforced by the code rather than by convention.
- **Chose `& ~bit` over `^` and `-`.** All three clear the bit on the first call; only `& ~bit`
  leaves the mask unchanged on the second. Edge case E9 asks for exactly that, so **the requirement
  picked the operator** — it was not a style choice.
- **Adjacency and direction fall out of one calculation.** Comparing `b - a` against each
  `Direction.delta` finds the direction, and "no match" *is* the not-adjacent case. Equal cells and
  diagonals are rejected by the same code, with no special branch.
- **Exception messages now carry the coordinates**, and each check names which of `a` or `b` is at
  fault. `walls_at` was brought in line. §IV.2 asks for a clear message; a generator that calls this
  thousands of times also needs to know *which* call failed.
- **Docstrings converted to the NumPy sections** javi documented in
  `Docs/python-docstrings_guide.md`. Agreed with him in conversation to use one style project-wide,
  which closes the open question in §9 of his guide.
- **Five tests added, twelve in total** — `commit 3959e75` and the working tree. Split so each one
  asserts a single property, and `pytest -v` now reads as the list of guarantees `Maze` makes.

## 4. Learned / 学んだこと

written up:

- [`bitmask-wall-encoding.md`](../learning_log/bitmask-wall-encoding.md) — clearing a bit with `~`,
  and why the idempotence requirement leaves only one usable operator.

  check that a test can actually fail.

The one worth carrying forward: **a test that passes proves nothing until you have seen it fail.**
Two of today's tests were checked by swapping in a broken `open_passage` — one that updates a single
side, and one that toggles instead of clearing. Both were caught, and that is the only reason I
believe the tests are doing their job.
