# コード解説 — A-Maze-ing のすべてのモジュール

この文書群は、**so と javi が書いたコードと、その構造のすべて**を、半年後の自分や相方が読み直しても理解できるように説明するものです。

- **省略しない:** すべてのファイル・クラス・関数を扱います。
- **そもそもの概念から:** 「全域木とは何か」「キューとは何か」「ビットで壁を表すとは」から説明します。
- **仕組みを見せる:** 実際にコードを動かして得た値でトレース(1 手ずつの追跡)を載せます。
- **関係を図にする:** どのメソッドがどのメソッドを呼ぶかを図で示します。

> 現在は**日本語版のみ**です。英語版は同じ構成で後から作ります。

## 各章の構成

どの章も、次の順番で書いてあります。

1. **この章で分かること**
2. **そもそもの概念** — そのモジュールが扱う考え方そのもの
3. **全体図** — モジュールの中の部品と、その関係
4. **各クラス・関数** — シグネチャ、何をするか、処理の手順、送出する例外、呼ぶもの・呼ばれるもの
5. **トレース** — 実際の値で 1 手ずつ追ったもの
6. **注意点・よくある誤解**
7. **関連文書**

## 図の凡例

| 図の種類 | 使う場面 | 例 |
| --- | --- | --- |
| ASCII 図(等幅の文字の図) | 形そのものが大事なもの:迷路、ビットの並び、セルの配置、画面の出力 | `+---+---+` |
| mermaid 図 | 流れや関係:処理の順番、呼び出し関係、モジュールの依存 | ` ```mermaid ` のブロック |

mermaid 図は GitHub ではそのまま図として表示されます。VS Code で見るには、Markdown の mermaid 表示に対応した拡張機能が必要です。

迷路の ASCII 図の読み方:

```text
+---+---+        + は角(かど)、--- は横の壁、| は縦の壁
| E     |        空白は開いている(通れる)ところ
+   +---+        E = 入口、X = 出口、o = 最短経路(画面と同じ印)、███ または # = 「42」のセル
                 (セルの配置だけを示す図では、. = 空いているセル)
|     X |
+---+---+
```

座標は常に `(x, y)` です。`x` は列(左から 0, 1, 2, …)、`y` は行(上から 0, 1, 2, …)で、左上が `(0, 0)` です。

## 用語集

| 用語 | 意味 | 詳しい章 |
| --- | --- | --- |
| セル | 迷路の 1 マス | 1 |
| 壁 | セルの北・東・南・西の 4 辺。閉じているか開いているか | 1 |
| マスク(ビットマスク) | 1 つのセルの 4 つの壁の状態を、4 ビットの整数 1 つで表したもの(0〜15) | 1 |
| 確保セル(reserved) | 「42」の形を描くために、壁を全部閉じたままにするセル | 1, 3 |
| 通路 | 開いている壁。隣り合う 2 つのセルをつなぐ | 1 |
| グラフ | 点(セル)と線(通路)でできた構造 | 3 |
| 全域木 | すべての点を、輪を作らずにつないだグラフ。完全迷路のこと | 3 |
| ループ(閉路) | 同じ通路を 2 度通らずに元のセルに戻れる道 | 3 |
| 行き止まり | 通路が 1 本しかないセル | 3 |
| braiding | 行き止まりの壁を開けてループを作る処理 | 3 |
| スタック | 最後に入れたものから取り出す入れ物(LIFO) | 3, 4 |
| キュー | 最初に入れたものから取り出す入れ物(FIFO) | 4 |
| DFS / BFS | 深さ優先探索 / 幅優先探索 | 3, 4 |
| シード | 乱数の出発点。同じシードからは同じ迷路ができる | 3 |
| 例外 | エラーを知らせる仕組み(`raise` で投げ、`except` で捕まえる) | 0 |
| ジェネレータ | 値を 1 つずつ渡す関数(`yield`) | 0, 1 |
| Protocol / ABC | 「このメソッドを持っていること」を型で表す 2 つの方法 | 0, 6 |
| wheel | インストールできる形にまとめた `.whl` ファイル | 8 |
